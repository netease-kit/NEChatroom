# تحليل وحدود إعادة البناء

- الحزمة الأصلية APK/APKS هي تطبيق Flutter مترجم، وليست مشروع Dart المصدر الأصلي.
- تم استخراج موارد Flutter وأصول مرئية متعددة. هذه الموارد لا تعيد بناء منطق التطبيق تلقائيًا.
- التطبيق الأصلي يتضمن دلائل على غرف صوتية، فيديو، هدايا، عملات، ألعاب، عائلات، وكالات، VIP، ومزايا اجتماعية.
- قاعدة Supabase التي تم فحصها تحتوي جداول للملفات الشخصية والغرف والرسائل والمحافظ والهدايا والعائلات والوكالات والإشعارات وVIP.
- تم فحص سياسات RLS؛ لذلك يستخدم هذا المشروع الجلسة الحالية ولا يضع مفتاح service role في العميل.
- Edge Function باسم agora-token موجودة، لكن تكامل Agora داخل عميل Flutter لم يكتمل ولم يتم التحقق من إعدادات Agora أو تجربة المكالمات.
- وظيفة imchat-api الموجودة لا تغطي كل مسارات API القديمة، ولا ينبغي اعتبارها بديلًا كاملًا للسيرفر القديم.
- ملفات الأصول كبيرة (أكثر من 140MB) ولذلك لم تُضمّن في هذا الفرع. توجد حزمة أصول منفصلة يمكن إضافتها محليًا أو استضافتها في Git LFS/Storage.
- لم يتم إجراء flutter analyze أو flutter build apk لعدم توفر Flutter SDK في بيئة التنفيذ المستخدمة.
