# مشروع إعادة بناء Im Chat

هذا مجلد مستقل داخل المستودع لإعادة تنفيذ تطبيق Im Chat اعتمادًا على ملف التثبيت المرفوع `Im Chat_1.0.15.apks`.

## الحالة الحالية
- [x] إنشاء هيكل Flutter أولي وشاشات تنقل عربية.
- [x] توثيق بنية الحزمة والأصول التي أمكن فحصها من `base.apk`.
- [x] إضافة أداة استخراج الأصول من ملف APKS محليًا.
- [ ] إدخال الأصول المستخرجة في المستودع (لم تُرفع ملفات الصور الثنائية في هذه الدفعة).
- [ ] مطابقة كل شاشة بصريًا مع لقطات مرجعية.
- [ ] تنفيذ التسجيل والحساب والغرف والرسائل والملف الشخصي.
- [ ] ربط Supabase بعد اعتماد الهيكل.
- [ ] دمج الصوت/Agora والهدايا والمحفظة والألعاب وبقية الخدمات.
- [ ] اختبار Android وبناء APK.

## التشغيل
1. ثبّت Flutter stable.
2. من هذا المجلد نفّذ `flutter pub get`.
3. نفّذ `flutter run`.

## استخراج الأصول
ضع ملف `Im Chat_1.0.15.apks` بجوار مجلد المشروع ثم نفّذ:

```bash
python3 tools/extract_assets.py "../Im Chat_1.0.15.apks"
```

سيتم استخراج أصول Flutter المرئية فقط إلى `assets/original/`، دون تضمين ملفات APK أو المكتبات الثنائية أو بيانات اعتماد التطبيق.

## ملاحظة مهمة
ملف APKS يحتوي تطبيق Flutter مبنيًا (AOT)، وليس مشروع Dart الأصلي. لا يمكن استرجاع كود Dart الأصلي كاملًا من هذا الملف؛ لذلك هذا المشروع إعادة تنفيذ مستقلة وليست نسخة مفكوكة من المصدر الأصلي. الشاشات الحالية نقطة انطلاق وليست مطابقة نهائية.
